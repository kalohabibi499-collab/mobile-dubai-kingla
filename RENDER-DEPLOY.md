# Deploy securely to Render

1. Create a **private GitHub repository** and upload only the contents of this folder.
2. Confirm `.env` is NOT in the repository.
3. In Render, choose **New > Blueprint** and connect the private repository. Render will detect `render.yaml`.
4. When prompted, set:
   - `MONGODB_URI`: your MongoDB Atlas connection string.
   - `ADMIN_USERNAME`: your private admin username.
   - `ADMIN_PASSWORD`: a new unique password of at least 16 characters.
   `SESSION_SECRET` is generated by Render from `render.yaml`.
5. Deploy. Health check path is `/healthz`.
6. Open the assigned `https://<name>.onrender.com` URL and sign in through `/portal.html`.
7. If you later add a custom domain, add `PUBLIC_ORIGIN=https://yourdomain.com` in Render Environment. You can list multiple allowed origins separated by commas.
8. In MongoDB Atlas, use a dedicated database user with only the permissions required by this application. Do not reuse your Atlas owner/admin account credentials.
9. If an old project ZIP with `.env` was ever shared, rotate the MongoDB and admin passwords before going live.

## Manual Render Web Service alternative
Build command: `npm ci --omit=dev`
Start command: `npm start`
Health check: `/healthz`

Do not upload a `.env` file to GitHub. Enter secrets in Render's Environment page.
